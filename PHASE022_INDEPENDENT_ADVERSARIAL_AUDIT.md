## Independent Adversarial Verdict

The V22 research core is honest but overstated, and the V22 submission package
is broken. Every fresh-cohort number recomputes bit-exactly; the inferential
frame around those numbers (significance, robustness, preregistration, effect
size) does not survive scrutiny; the counterfactual-fidelity "validation" is
circular by construction; one of three "untouched" holdouts was consumed by an
earlier experiment; and -- decisively -- **the packaged submission cannot run
under the competition loader**: its entrypoint raises `NameError: __file__` on
every step, so the certified "submission" is a silent all-PASS agent scoring
$3,000.00. The packaged QA passed it because its assertions (DONE, reward > 0)
are satisfied by a dead agent.

### 2. What failed scrutiny

- **Standalone submission (ENGINEERING, release-blocking).** Under
  `kaggle_environments` 1.32.7 -- the competition loader, which `exec`s agent
  sources without `__file__` -- packaged `main.py` raises `NameError` every
  step; actions fall back to PASS; score $3,000.00 (starting money) vs V3's
  $185,041 and $149,763 head-to-head. Reproduced 3x; root cause confirmed by
  direct `exec` replication and by a control run through a `__file__`-supplying
  wrapper ($185,041, deterministic). The shipped QA certified the corpse
  (DONE + reward > 0 + $3k==$3k "determinism").
- **Counterfactual fidelity as empirical validation.** `delta_money_realized`
  is assigned from `delta_money` at evaluation (`win_model.py:373-374`) and
  never independently measured; the audit compares the value to itself with
  zero re-simulation (imported simulator unused). MAE = $0.00 is generated by
  construction. Claim must be withdrawn, not softened.
- **Tournament holdout 340300..340349.** EXP-AEC-004 ran 100 matches there
  (Sept 18, real scores and commits). "100% Untouched" is false; the cohort
  must be re-designated.
- **Statistical-significance framing.** No Phase 022 preregistration exists;
  the program's documented primary (one-sided t) fails (p ~= 0.43); the
  headlined Wilcoxon (p = 0.034) is historically secondary, unadjusted for
  multiplicity, and flips at seed level (Wilcoxon p = 0.051, median $0).
  "Robust / decisive / stable positive shift" is spin on d = 0.03.
- **"Sub-100ms" performance framing.** P95/P99/max (229/405/2347 ms) exceed
  100 ms; the JSON's own `within_limit` is false; the 9-stage table is
  unsourced (telemetry has 6 fields); matches are 719 steps, not 720.
- **Safety/suite metrics in parts.** The `safety_violations` counter is
  structurally zero; `purchase_ok`/`market_collision_ok` unevaluated; macro
  test misreported and near-tautological; LIQ/SHUT live paths never executed.
- **Determinism scope.** Verified: aggregate equality (plus FULL-arm
  re-execution). Unverified: the claimed "720/720 steps bit-identical"
  trajectory identity. Packaged check void (dead agent).
